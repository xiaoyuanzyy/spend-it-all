# 花不完不许走 - 微信小程序

一款解压小程序：帮助世界文明的富豪花钱。通过转盘随机抽取富豪，置办奢华商品，体验挥霍乐趣。

## 🚀 上线步骤

### 前置准备

1. 注册微信小程序账号：https://mp.weixin.qq.com/
2. 获取小程序 AppID（个人测试可使用「测试号」）
3. 安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 第一步：导入项目

1. 打开微信开发者工具
2. 选择「导入项目」
3. 项目目录：选择 `spend-it-all/miniprogram` 文件夹
4. AppID：填入你的 AppID（测试号也可）
5. 项目名称：`花不完不许走`
6. 点击「导入」

### 第二步：开通云开发

1. 登录微信开发者工具后，点击工具栏「云开发」按钮
2. 点击「开通」
3. 选择「新建环境」
4. 环境名称：`spend-it-all-prod`
5. 付费方式：选择「按量付费」（个人测试足够）
6. 开通完成后，**记下环境 ID**（形如 `spend-it-all-prod-xxxxxx`）

### 第三步：配置环境 ID

打开 `miniprogram/app.js`，找到：

```js
wx.cloud.init({
  env: 'your-env-id', // ← 替换这里
  traceUser: true
});
```

把 `your-env-id` 替换为你的环境 ID。

### 第四步：上传云函数

在微信开发者工具中：

1. 右键点击 `cloudfunctions/login` 文件夹 → 选择「上传并部署：云端安装依赖（不上传 node_modules）」
2. 等待上传完成
3. 重复此操作上传以下所有云函数：
   - login
   - getBillionaire
   - getProducts
   - saveBill
   - getBills
   - deleteBill
   - clearBills
   - createRoom
   - joinRoom
   - startRoom
   - getRoom
   - saveProfile
   - getProfile

> 💡 也可以右键点击 `cloudfunctions` 父目录 → 「同步云函数列表」→ 一键部署全部

### 第五步：创建数据库集合

在云开发控制台 → 「数据库」→ 创建以下集合：

| 集合名 | 用途 | 权限建议 |
|--------|------|----------|
| `billionaires` | 富豪数据 | 仅创建者/管理员可写，所有人可读 |
| `bills` | 用户账单 | 仅创建者可读写 |
| `rooms` | 对战房间 | 所有人可读，仅创建者可写 |
| `profiles` | 用户档案 | 仅创建者可读写 |

权限配置路径：云开发控制台 → 数据库 → 对应集合 → 「权限设置」

### 第六步：导入富豪数据（可选）

云函数已经内置了 8 位富豪的兜底数据。如果需要自定义富豪：

1. 在云开发控制台 → 数据库 → `billionaires` 集合
2. 点击「导入」→ 选择 JSON 格式
3. 字段格式：
```json
[
  {
    "name": "埃隆·马斯克",
    "companies": ["特斯拉", "SpaceX", "X"],
    "assets": 250000000000,
    "tags": ["疯狂创新者", "推特整活", "火星人"],
    "catchphrase": "让人类成为多星球物种",
    "avatar": ""
  }
]
```

### 第七步：提交审核上线

1. 微信开发者工具 → 右上角「上传」
2. 填写版本号（如 1.0.0）和项目备注
3. 上传成功后，登录微信公众平台（mp.weixin.qq.com）
4. 「版本管理」→ 找到刚上传的版本 → 「提交审核」
5. 审核通过后点击「发布」即可上线

1. 在微信开发者工具中打开项目

## 🐛 常见问题

**Q1：云函数调用失败，提示 cloud has not been initialized**
→ 检查 `app.js` 中 `env` 是否替换为你的环境 ID

**Q2：转盘不会停在指定位置**
→ 检查 `pages/index/index.js` 的 `onSpin` 中角度计算

**Q3：多人对战一方看不到对方**
→ 当前使用 2 秒轮询，可改为 WebSocket 实时同步

**Q4：账单列表加载失败**
→ 检查云开发控制台中 `bills` 集合是否已创建

**Q5：真机预览时震动没反应**
→ `wx.vibrateShort` 在 iOS 上需要真机才能触发
